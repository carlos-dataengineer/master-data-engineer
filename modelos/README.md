# Modelos de referência

O Master Data Engineer foi concebido por engenharia reversa de padrões arquiteturais e operacionais de três projetos públicos. As fontes oficiais e as responsabilidades dos conceitos aproveitados estão registradas abaixo.

| Referência | Uso no Master Data Engineer | Fonte oficial |
|---|---|---|
| Pstack | Orquestração, skill de entrada, playbooks e delegação | https://github.com/cursor/plugins/tree/main/pstack |
| Thermos | Revisão paralela, corretude, segurança e manutenibilidade | https://github.com/cursor/plugins/tree/main/thermos |
| Ponytail | Princípios de simplicidade, causa raiz, escopo e validação | https://github.com/DietrichGebert/ponytail |

A adaptação resultante é específica para Engenharia de Dados no Databricks. Ela não é uma cópia integral, não é endossada pelos mantenedores dos modelos e não substitui os repositórios originais.

As cópias completas dos modelos foram preservadas na pasta `modelos/` do pacote local de trabalho. Para atualizações ou inspeção das fontes mais recentes, consulte os repositórios oficiais acima. Cada projeto mantém sua própria licença e atribuição.
