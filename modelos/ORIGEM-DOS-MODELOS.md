# Modelos de referência

Os diretórios `Pstack/`, `Thermos/` e `Ponytail/` são cópias dos projetos de referência recebidos. Seus arquivos internos foram copiados sem adaptação para esta entrega. Os arquivos ZIP originais também estão preservados em `arquivos-originais/`.

| Projeto | Origem | Licença declarada pelo projeto |
|---|---|---|
| Pstack | https://github.com/cursor/plugins/tree/main/pstack | MIT (`Pstack/LICENSE`) |
| Thermos | https://github.com/cursor/plugins/tree/main/thermos | MIT (`Thermos/LICENSE`) |
| Ponytail | https://github.com/DietrichGebert/ponytail | MIT (`Ponytail/LICENSE`) |

## Integridade dos arquivos recebidos

Foram recebidos dois arquivos `plugins-main.zip` idênticos. O segundo não foi duplicado nesta pasta para evitar armazenamento redundante.

- `plugins-main.zip` SHA-256: `293a3782158c3565300ec32cad67c6d8eda1bc14bb8a0ca3d348cbc0dad38e33`
- `ponytail-main.zip` SHA-256: `fb1e4285aaa30fa1667d7c644f8a28142392d27ec719bf11564627c6fdb63d83`

As cópias extraídas dos projetos permanecem disponíveis acima. Os pacotes de origem completos permanecem preservados em `arquivos-originais/`, incluindo componentes do repositório de plugins que não foram necessários na primeira adaptação. Cada projeto mantém seu próprio arquivo de licença e seus metadados de origem. A inclusão destes modelos não atribui automaticamente uma licença aos arquivos novos em `criação/`.
